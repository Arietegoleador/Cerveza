# PWA Consumo de cerveza

PWA local para iPhone, sin cuenta ni servidor.

## Archivos
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- icon.svg

## Datos iniciales
Incluye los totales semanales históricos facilitados y los datos diarios reales del 7–13 de septiembre de 2026.

El récord diario inicial de 230 cl se conserva aunque los datos diarios iniciales no contengan ese día.

## Nota histórica
Los totales semanales antiguos se mantienen como agregados. Para las estadísticas mensuales de julio/agosto se prorratean por días únicamente para cerrar el mes; no se presentan como registros diarios reales.

## Uso
Subir todos los archivos juntos a un alojamiento HTTPS que permita PWA. Abrir en Safari del iPhone y usar "Añadir a pantalla de inicio".
